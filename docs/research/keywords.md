## 1. Method and Limitations

**Working input note:** The client supplied keyword clusters (serious state felonies, federal defense, white-collar/fraud) and suggested sentencing-by-felony-level pages. The full original client document was not available in the repo; the clusters above are the working input for this file, and any head terms in the original document beyond these clusters are not covered here. If the original document resurfaces, diff it against this file.

**Method:**
- All SERPs captured 2026-07-22 via WebSearch (30+ queries across three clusters, plus long-tail, local-modifier, and Spanish-language queries).
- For each keyword: intent classification, top organic results as returned, winnability grade (NOW / 6-12mo / YEARS / SKIP), and reasoning tied to observed SERP composition.

**Limitations (systematic, apply to everything below):**
1. The search tooling approximates a US-general Google SERP. It does NOT reproduce a Tampa- or Brandon-geolocated SERP. Result ordering may differ from a true in-market SERP; ranks recorded are the order results were returned (treat exact positions as approximate).
2. The local pack, map results, ads, and Google Business Profile data are NOT renderable with this tooling on any query (verified limitation this session). Every local-pack observation in this file is an indirect proxy (trustanalytica, Birdeye, Yelp, BBB, Avvo review counts seen in SERP snippets) and is labeled "reported," or is labeled inferred/ESTIMATE.
3. Confidence labels used throughout: **verified** (seen directly in this session's SERPs), **reported** (third-party claim seen in a snippet or aggregator, not independently confirmed), **inferred** (judgment grounded in verified observations), **ESTIMATE** (number not observed; basis stated).
4. No absolute search-volume numbers were observed this session. All volume statements are ESTIMATE with stated basis (usually density of dedicated competitor pages).
5. An attempted fetch of Justia's Tampa white-collar directory page returned HTTP 403; directory-depth counts are unavailable (gap recorded). A direct census.gov fetch also returned 403; the Hispanic-population figure is reported via snippets citing Census QuickFacts.
6. All winnability grades are inferred judgments grounded in verified SERP composition.

**Recommended follow-up before the dossier is finalized:** a manual or geo-emulated (Brandon/Tampa coordinates) Maps and local-pack audit. This matters most for "felony lawyer Brandon FL," where proximity is a ranking factor and the pack could not be observed.

**Florida Bar compliance framing used below:** several competitors rank with titles like "Best," "Top," or "Expert." These are flagged OBSERVED-NOT-RECOMMENDED. Unverifiable superiority claims implicate Fla. Bar Rule 4-7.13; "expert/specialist" language is lawful only with board certification under Rule 4-7.14. Hines & McCarty must not mirror these absent certification.
